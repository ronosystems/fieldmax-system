How to Process a Return
If you have the Sale ID:
  1. Enter the Sale ID and click "Find Sale"
  2. Use the filter box to quickly find the product by code or SKU
  3. Click on the product to select it
  4. Complete the return details
If you have the Product Code:
  1. Enter the Product Code and click "Find Product"
  2. Use the filter box to quickly find the correct sale by Sale ID
  3. Click on the sale to select it
  4. Complete the return details
